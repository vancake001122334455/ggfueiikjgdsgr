# 🚀 Инструкция: Как выложить сайт PoizonVanart на хостинг

Платформа полностью готова к публикации в интернете: в ней нет внешних тяжелых зависимостей, сервер работает на чистом Node.js (версии 18, 20 или 22), а порт автоматически берётся из переменной `PORT` хостинга.

---

## ⚡ Способ 1. Самый простой (Railway.app или Render.com)
*Подходит, если нет своего сервера и хочется поднять сайт за 5 минут с бесплатным HTTPS-адресом.*

### На Railway (рекомендуется):
1. Зарегистрируйтесь на **[railway.com](https://railway.com)** (вход в 1 клик через GitHub).
2. Нажмите **«New Project»** ➔ **«Deploy from GitHub repo»** (предварительно загрузив файлы проекта в свой приватный репозиторий GitHub) **ИЛИ** выберите **«Empty Project»**.
3. Railway автоматически обнаружит `package.json`, запустит `npm start` и выделит публичный адрес (например: `poizonvanart.up.railway.app`).
4. Для сохранения заказов и базы данных добавьте том (Volume):
   * В настройках сервиса перейдите во вкладку **Volumes** ➔ **Add Volume**;
   * Укажите путь монтирования: `/app/project/data`.
5. Сайт готов и доступен для всего мира!

## 🇷🇺 Способ 2. Российский VPS (Timeweb Cloud, Reg.ru, Beget, Selectel)
*Подходит, если нужен сервер в РФ или Беларуси, оплата картой МИР / Белкарт и привязка своего домена (например, `poizonvanart.ru` или `poizonvanart.by`).*

### 1. Аренда сервера:
* Закажите самый простой облачный сервер (VPS/VDS) на **Ubuntu 22.04 / 24.04** (хватит минимального тарифа: 1 CPU, 1-2 ГБ RAM, стоимость около 200–350 ₽/месяц).

### 2. Подключение к серверу:
Откройте терминал (или PowerShell / PuTTY на Windows) и подключитесь:
```bash
ssh root@ВАШ_IP_СЕРВЕРА
```

### 3. Установка Node.js (занимает 1 минуту):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs unzip git
```

### 4. Загрузка проекта:
Загрузите архив `poizonvanart.zip` на сервер (через FileZilla или команду `scp`):
```bash
# распаковать архив в папку сайта:
mkdir -p /var/www/poizonvanart
unzip poizonvanart.zip -d /var/www/poizonvanart
cd /var/www/poizonvanart
```

### 5. Запуск на постоянную работу (через PM2):
PM2 гарантирует, что сайт будет работать круглосуточно и автоматически перезапустится при перезагрузке сервера:
```bash
npm install -g pm2
PORT=80 pm2 start project/server/index.js --name "poizonvanart"
pm2 save
pm2 startup
```
*Теперь сайт сразу открывается по адресу `http://ВАШ_IP_СЕРВЕРА`!*

### 6. Привязка своего домена (HTTPS / SSL):
Установите бесплатный сертификат Let's Encrypt через Nginx или Caddy:
```bash
apt-get install -y caddy
```
В файле `/etc/caddy/Caddyfile` укажите:
```caddy
ваш-домен.ru {
    reverse_proxy 127.0.0.1:80
}
```
И перезапустите:
```bash
systemctl restart caddy
```
Caddy сам бесплатно выпустит вечный SSL-сертификат (зелёный замочек HTTPS).

## 🐳 Способ 3. Запуск через Docker (в 1 команду)
Если на вашем сервере установлен Docker:
```bash
docker compose up -d --build
```
Контейнер соберется сам, поднимет порт `8080`, настроит базу данных в папке `./project/data` и будет автоматически перезапускаться при сбоях (`restart: unless-stopped`).
