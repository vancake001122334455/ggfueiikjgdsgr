# Инструкция: Как развернуть PoizonVanart на Railway (хостинг)

Платформа **PoizonVanart** уже полностью готова к облачному деплою на **Railway** — здесь есть `package.json`, чистый Node.js без внешних бинарных зависимостей, встроенный веб-сервер с поддержкой `0.0.0.0` и автоматический перехват порта `$PORT`.

---

## Вариант 1. Через GitHub (Рекомендуемый, 3 минуты)

Это самый простой и надёжный способ. При каждом коммите Railway будет сам обновлять сайт.

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите зелёную кнопку **New** (создать новый репозиторий).
3. Назовите его, например, `poizonvanart`, выберите **Private** или **Public**, нажмите **Create repository**.
4. Загрузите файлы из архива в репозиторий:
   * Либо через кнопку **Upload files** прямо на сайте GitHub;
   * Либо через терминал (Git):
     ```bash
     git init
     git add .
     git commit -m "PoizonVanart v2.8"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/poizonvanart.git
     git push -u origin main
     ```

### Шаг 2. Развертывание на Railway
1. Перейдите на сайт [railway.app](https://railway.app) и авторизуйтесь (через GitHub).
2. Нажмите **+ New Project**.
3. Выберите **Deploy from GitHub repo**.
4. Выберите созданный репозиторий `poizonvanart`.
5. Нажмите **Deploy Now**.
6. Railway автоматически:
   * Обнаружит Node.js;
   * Запустит контейнер;
   * Привяжет нужный порт.

### Шаг 3. Включите публичный HTTPS-домен
1. В панели Railway кликните по вашему проекту / сервису.
2. Перейдите во вкладку **Settings**.
3. Пролистайте до раздела **Networking**.
4. Нажмите **Generate Domain**.
5. Вы получите готовый бесплатный адрес с SSL-сертификатом вида:  
   `https://poizonvanart-production.up.railway.app`

## Вариант 2. Через Railway CLI (Без GitHub, из терминала)

Если не хотите использовать GitHub, можно задеплоить проект напрямую из папки с компьютером:

1. Откройте командную строку (cmd) в папке проекта.
2. Установите CLI Railway (если ещё не установлен):
   ```bash
   npm install -g @railway/cli
   ```
3. Войдите в аккаунт Railway:
   ```bash
   railway login
   ```
   (В браузере откроется окно подтверждения — нажмите «Authorize»).
4. Инициализируйте проект:
   ```bash
   railway init
   ```
   (Выберите «Create a new project» и введите название `poizonvanart`).
5. Запустите деплой:
   ```bash
   railway up
   ```
6. Сгенерируйте домен:
   ```bash
   railway domain
   ```

## Полезные настройки в панели Railway (Вкладка Variables)

В панели Railway откройте вкладку **Variables** и при желании добавьте:

| Переменная | Значение | Зачем нужно |
|---|---|---|
| `NODE_ENV` | `production` | Включает оптимизированный режим Node.js |
| `PUBLIC_URL` | `https://ваш-домен.up.railway.app` | Ссылки реферальной программы и «Поделиться корзиной» будут вести на ваш домен |
| `PV_QUIET` | `1` | (Опционально) Уменьшает количество логов в консоли |

## Сохранение базы данных (Persistent Volume)

В Railway база хранится в JSON-файле (`project/data/db.json`). Чтобы при повторных деплоях данные пользователей и заказов сохранялись:

1. В проекте на Railway нажмите **+ New** → **Volume**.
2. В настройках Volume укажите путь монтирования (Mount Path):  
   `/app/project/data`
3. Нажмите **Save**. Теперь база данных пользователей, заказов и оплат сохраняется на постоянный диск.
