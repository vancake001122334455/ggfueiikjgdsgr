# PoizonVanart · Инструкция по запуску в 1 клик и новые функции

## 🚀 Как запустить платформу в 1 клик

Для любого устройства и операционной системы подготовлены скрипты запуска:

### 1. Windows (в 1 клик)
- Дважды кликните по файлу **`start.bat`**.
- Скрипт проверит наличие Node.js, запустит локальный сервер и автоматически откроет сайт `http://localhost:8080` в браузере по умолчанию.

### 2. macOS / Linux (в 1 клик)
- Запустите скрипт через терминал или двойным кликом:
  ```bash
  ./start.sh
  ```
  *(или `bash start.sh`)*
- Сервер автоматически стартует и откроет браузер.

### 3. Через npm / Node.js
```bash
npm start
```
или запуск кроссплатформенного лаунчера с открытием браузера:
```bash
node run.js
```

### 4. Через Docker (для серверов и контейнеров)
```bash
docker compose up -d
```
Сайт сразу станет доступен на порту `8080`.

## 🌟 Новые ключевые возможности платформы

### 1. Оплата частями (50/50 и «Долями»)
- **Безопасная сделка 50/50**: 50% оплачивается сразу (выкуп товара на маркетплейсе Poizon в Китае), а вторые 50% — только после того, как товар поступил на склад и клиент увидел детальный фотоотчёт перед отправкой в РФ/РБ. Предоставляет максимальный уровень доверия покупателям.
- **Оплата «Долями» (4 платежа)**: заказ делится на 4 равных платежа по 25% каждые 2 недели (0% переплат и скрытых комиссий). Первый платёж списывается в момент оформления, остальные 3 — по наглядному графику.
- **Интерактивный график рассрочки в заказе**: отображает прогресс-бар, статус каждого транша («✓ Оплачен» / «Ожидает») и кнопку быстрой доплаты следующей части.

### 2. Интеграция службы доставки СДЭК и выбор ПВЗ
- **Интерактивный выбор ПВЗ**: фильтрация пунктов выдачи по городам (Москва, Санкт-Петербург, Минск, Екатеринбург, Казань, Новосибирск и др.).
- **Полная карточка пункта выдачи**: адрес, ближайшая станция метро, режим работы, наличие примерочных кабинок и терминалов оплаты.
- **Способы доставки**:
  - *СДЭК ПВЗ* (бесплатное хранение 7 дней, включено в базовый карго-тариф);
  - *СДЭК Курьер* (доставка до двери лично в руки с интервалом вручения);
  - *Самовывоз из логистического хаба Vanart Cargo* (Москва-Сити / Минск, Победителей 65).
- Трекинг-номер СДЭК с быстрой ссылкой на официальный трекер `cdek.ru`.

### 3. Фотоотчёт со склада и полноэкранная Lightbox-галерея
- **Детализированные фотографии инспекции**:
  1. *Фирменная бирюзовая пломба Legit Check* с уникальным серийным номером (PZ-...) и штрих-кодом;
  2. *Оригинальный сертификат подлинности Dewu Authenticity Certificate* с защитным QR-кодом и защитной голограммой;
  3. *Контрольное взвешивание* на калиброванных платформенных весах с ярким светящимся цифровым табло;
  4. *Оригинальная коробка Poizon* с контролем геометрии углов и защитным брендовым скотчем.
- **Lightbox-просмотрщик с зумом**:
  - Режим приближения 2x для макро-инспекции швов, QR-кодов и серийных номеров;
  - Перелистывание фото стрелками мыши и клавиатуры (← / →);
  - Кнопка прямого скачивания оригиналов фото в максимальном разрешении;
  - Штамп «Dewu Legit Check Verified».

### 4. Автопарсер ссылок Poizon и сравнение цен с ритейлом
- Автоматическое распознавание ссылок Poizon/Dewu (`dw4.co/t/...`, `dewu.com`, `poizon.com`) и артикулов (напр. `DD1391-100`, `HQ6316`, `555088-105`, `L47144100`, `FOG-HOOD-OAT` и др.).
- Моментальная подгрузка размерной сетки с актуальными ценами в CNY (юанях) для каждого размера.
- **Виджет «Сравнение цен и выгода»**: наглядное сопоставление итоговой стоимости «под ключ» через Vanart с розничными ценами в магазинах РФ и Беларуси (Street Beat, Rendez-Vous, ЦУМ), демонстрирующее экономию до 60%.
- Быстрый заказ по ссылке доступен на Главной, в Каталоге и в модальном окне «Заказ под ключ».

## 📱 Мобильная адаптация и Progressive Web App (PWA)

- **Bottom Navigation Bar**: на смартфонах ($\le 860\text{px}$) доступен нижний таб-бар с мгновенным доступом к Каталогу, Калькулятору, Корзине со счетчиком и Профилю.
- **Липкая панель покупки**: в карточке товара на мобильных устройствах цена и кнопка заказа всегда под рукой внизу экрана.
- **PWA**: возможность установки приложения на главный экран iOS и Android (`manifest.webmanifest`, Service Worker, offline-shell).
